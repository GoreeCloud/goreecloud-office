# Benefits

GoreeCloud Office is intended to provide:

- Local-first office productivity that remains useful without a server or account.
- A shared engine so Writer, Spreadsheet, Presentations, and Forms do not drift into incompatible foundations.
- Inspectable native file packages instead of an opaque application-only database.
- Portable import/export paths and explicit compatibility reporting.
- Platform-native clients while preserving one canonical document model.
- Privacy, security, accessibility, recovery, and interoperability as architectural requirements rather than later additions.

These are product objectives. Only capabilities documented in `CAPABILITIES.md` as verified current state should be treated as implemented.
