# Branding

## Product Identity

The canonical family name is GoreeCloud Office Suite. The shared start application may be described as GoreeCloud Office in repository and product documentation.

Ordinary installed application labels should use concise approved short names such as Office, Writer, Spreadsheet, Presentations, and Forms rather than repeating the GoreeCloud prefix in launchers and equivalent operating-system surfaces.

## Visual Direction

All user-facing Office surfaces must use the current accepted Glaze UI contract. The document canvas must prioritize readability; translucency, blur, depth, and motion belong around the workspace rather than interfering with content.

## Current State

No production Office visual identity, icon set, launcher assets, or accepted Glaze UI application shell is implemented in this repository yet. Branding references here define direction only and do not establish visual conformance.

## Accessibility

Branding and interface identity must remain distinguishable without color alone and must support increased contrast, reduced transparency, reduced motion, scalable text, and accessible focus/state communication.
