# Feature Roadmap

## Phase 0 — Foundation

- [x] Select Rust shared-core architecture.
- [x] Define native Office package family.
- [x] Define import/export compatibility targets.
- [x] Define text/Unicode/font dependency architecture.
- [x] Define graphics/PDF/SVG/image dependency architecture.
- [x] Select AGPL-3.0-or-later for the primary repository.
- [ ] Merge the first Rust Office foundation through governed review and validation.
- [ ] Commit and enforce a reproducible Cargo lockfile.
- [ ] Establish branch/ruleset protection where available.

## Phase 1 — Office Engine

- [ ] Commands and undo/redo.
- [ ] Autosave and recovery journal.
- [ ] Canonical styles.
- [ ] Text engine.
- [ ] Layout and pagination.
- [ ] Graphics engine.
- [ ] Accessibility semantics.
- [ ] Printing/export.
- [ ] Templates.
- [ ] Current Glaze UI application shell.
- [ ] Nine-system platform evaluation with accepted evidence.

## Phase 2 — Writer

- [ ] Rich-text editing.
- [ ] Paragraph and character styles.
- [ ] Lists and headings.
- [ ] Tables.
- [ ] Images/drawing objects.
- [ ] Page layout.
- [ ] Headers/footers/page numbering.
- [ ] Comments.
- [ ] ODF/OOXML import/export.
- [ ] PDF export.
- [ ] Offline and recovery acceptance.

Later phases cover Spreadsheet, Presentations, collaboration, Forms, and Database.
