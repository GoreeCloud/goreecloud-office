# Development Notes

## Current Milestone

The repository is establishing the first bounded shared Office Engine foundation with Writer-oriented document state and reversible commands.

## Accepted Direction

- Shared Rust Office Engine.
- Writer first.
- Platform-native Android, web, and Linux presentation shells.
- One canonical document model.
- Native inspectable Office package formats.
- Shared text, graphics, style, chart, formula, command, accessibility, import/export, printing, recovery, and collaboration foundations over time.

## Current Non-Goals

The current milestone does not attempt to provide a usable editor, persistence, rendering, platform UI, synchronization, collaboration, or production deployment.

## Validation Rule

Source changes remain Development-only until the exact candidate revision passes required validation and is promoted through the governed pull-request workflow.
