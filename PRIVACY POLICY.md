# GoreeCloud Office — Privacy Policy

## Current Development Scope

The current repository contains local Rust library code for document state and reversible commands. It does not currently provide a network service, user account system, telemetry pipeline, advertising system, document persistence layer, synchronization service, or collaboration runtime.

## Privacy Principles

- Core editing must be usable without advertising or behavioral tracking.
- Basic local editing must not require a GoreeCloud account or network connection.
- Document content must remain within its authorized privacy boundary.
- Optional intelligence must not silently send private document content to external services.
- Generated or rewritten content must remain reviewable before insertion.
- Sharing, collaboration, synchronization, retention, export, and deletion must be explicit and governed.
- Telemetry must follow GoreeCloud privacy-by-default and product-improvement requirements.

## Current Data Handling

The implemented source keeps document state in memory only. No current repository runtime stores or transmits user documents because no usable runtime exists yet.

## Future Platform Authority

Privacy Shield will govern applicable permitted-use, minimization, retention, sharing, intelligence-processing, telemetry, export, deletion, and privacy-control requirements. Identity, Policy, Everkeep, Wardveil Security, and other systems retain their separate authorities.

## Release Boundary

This file describes repository privacy requirements and current Development behavior. It must be updated before any user-facing release, persistence layer, network feature, collaboration service, telemetry behavior, or external processing is introduced.
