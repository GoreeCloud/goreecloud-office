# User Manual — GoreeCloud Office

## Current Availability

GoreeCloud Office is not yet available as a usable application.

The current repository contains a shared-engine document and command foundation only. There is no supported installation package, Writer interface, web application, Android application, Linux desktop application, or production service.

## Current User Capability

There is no end-user Office workflow to document yet. The implemented code is development infrastructure for document state and reversible editing commands.

## Planned First Usable Experience

The initial usable product is intended to include Office home, Writer, local file handling, offline editing, autosave, crash recovery, rich text, styles, tables, images, page layout, comments, printing, import/export, templates, accessibility, and Glaze UI.

## File and Network Principle

Core editing is intended to work with ordinary local files while offline. Drive, Sync, Identity, collaboration, and other network services should enhance Office without becoming prerequisites for basic local editing.

## Maintenance

This pre-release manual must be replaced with verified step-by-step instructions as user-facing capabilities are implemented and validated.
