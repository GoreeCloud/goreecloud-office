# User Manual

## Current availability

GoreeCloud Office is not yet available as a usable editor.

There is currently no supported Office installation package, production web application, Android release, Linux desktop release, or Stable Office build.

## Current development artifact

This repository contains shared-engine development source for an initial Writer document model and native package parser/builder. These are developer-facing source components, not an end-user application.

This manual will gain step-by-step user instructions only as corresponding behavior is implemented and validated.
